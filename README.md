# 数据分析求职全栈知识库（校招版）

> 面向**国内校招数据分析岗（业务向）**的一站式开源知识库：**360道分行业SQL真题 × 6大知识模块 × 65道面试真题全解 × 2个可写进简历的实战项目**。所有内容围绕真实互联网/电商/金融/零售业务场景编写，标注【面试高频】【加分点】【避坑指南】，代码逐行注释，可直接当刷题手册和面试冲刺指南使用。

**⭐ 如果这个仓库对你有帮助，请点个 Star 让更多求职的同学看到！**

## 📌 这个仓库解决什么问题

校招数据分析岗的备考痛点，通常不是"资料太少"，而是：

1. **SQL刷题没有业务语境**——题库会教语法，但面试官问的是"复购率怎么算才对"；本库 360 道题全部带真实业务背景、表结构、口径辨析和两种解法对比；
2. **知识碎片化**——统计、Excel、Python、BI、数仓散落在各个课程里；本库按"面试考察密度"重新组织成 6 个模块，每个知识点自带业务案例和面试问答；
3. **业务面没有参考答案**——"GMV跌了10%怎么分析"这类题网上只有零散帖；本库 65 道真题给出完整的高分框架与参考答案；
4. **简历项目缺素材**——本库提供 2 个从数据清洗到策略建议的完整项目，附简历话术与追问预演。

## 🎯 适用人群

- 准备**校招/实习**投递数据分析、商业分析、数据运营岗位的应届生（本科/硕士均可，文理科通用）；
- 想转行数据分析、需要系统性自查知识盲区的 1-3 年内职场人；
- 带教校招新人的面试官/mentor：可直接取用其中的真题与评分要点。

## 🚀 快速开始（按你的剩余时间选路线）

**距离面试还有 30 天（推荐）**

| 周次 | 内容 |
|---|---|
| 第1周 | `00-SQL备考总攻略` → 2个目标行业的**入门级**45题全部手写跑通 |
| 第2周 | 目标行业**进阶级** + 《01-统计学基础》《06-业务分析方法论》 |
| 第3周 | 目标行业**高级篇**（连续行为/漏斗/归因题重点）+ 《03-业务面30道》口头作答 |
| 第4周 | 《02-技术面20道》《03-HR面15道》 + 1个实战项目完整复现并写进简历 |

**距离面试只有 7 天**：总攻略八股20问 → 高级篇的"连续登录/留存/漏斗/同环比"四类题 → 业务面Q1-Q6（异动类）→ 项目一只看"简历话术+追问预演"。

**SQL 零基础**：先学 SELECT/GROUP BY/JOIN 三件套（任何入门教程），然后直接进入入门级分册——本库每题都从口径讲起，边刷边学效率最高。

## 🏷 标签体系

全库统一三类标签，检索复习时按标签过滤效率最高：

- **【面试高频】**：近年校招笔面反复出现的考点，必须形成肌肉记忆；
- **【加分点】**：多数候选人答不出的进阶点，答出即拉开差距（如 SRM 检查、对数分解、validate 参数）；
- **【避坑指南】**：面试官专门用来筛人的坑（JOIN 翻倍、p 值误读、平均的平均、时间边界差一天……）。

## 💡 使用建议（重要）

1. **SQL 必须动手**：所有题目建议在本地 MySQL 8.0 或在线题库环境实际运行——"看懂"和"写对"之间隔着 20 遍的练习量；
2. **业务题先自答再对照**：每道业务/HR 面真题先计时 3 分钟口头作答，再看参考答案找差距，直接看答案的留存率接近 0；
3. **项目要改造成自己的**：实战项目提供的是完整骨架，请替换成自己理解的业务设定与数字，否则面试深挖时容易露馅；
4. **方言说明**：SQL 以 MySQL 8.0 为主（涉及大数据量处标注 Hive/Spark SQL 差异），Pandas 版本 ≥1.5，Excel 区分 M365 动态数组与传统函数。

## 🤝 贡献指南

欢迎 PR！三类贡献尤其欢迎：

1. **题目补充**：新行业（如汽车/医疗/跨境）或新题型的 SQL 真题，请遵循现有 7 模块结构；
2. **答案迭代**：业务面参考答案永远可以更贴合真实业务，欢迎附上你的实战版本；
3. **勘误**：代码在特定 MySQL 版本的兼容性问题、口径表述不严谨之处，请提 Issue 注明文件与行号。

提交规范：`feat(电商): 新增直播带货ROI分析题` / `fix(统计学): 修正样本量公式排版`。
