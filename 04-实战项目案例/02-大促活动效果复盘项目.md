> 与项目一互补：项目一练"诊断与策略"，本项目练"**活动评估与ROI**"——校招面试中"复盘一次活动"是出现率最高的项目类问题。同样附简历话术与追问预演。代码基于 pandas，模拟数据口径贴近真实。

## 一、项目背景与目标

**业务设定**：某美妆电商平台（年GMV约15亿），6月举行年度最大促"618狂欢节"（周期：5月31日-6月20日，含预售期/开门红/返场期三个阶段）。核心目标：**活动期GMV 2.4亿（同比+40%）**，拉新10万人，毛利率不低于日常的85%。

**复盘要回答的五个问题**：

1. 目标达成没有？差距在哪个阶段、哪个人群？
2. 增长是"真增量"还是"把日常销量搬到了活动期"（透支）？
3. 补贴（券+定金膨胀+满减）花得值不值？ROI多少？哪类券效率最高？
4. 拉来的10万新客质量如何？（30日留存 vs 日常新客）
5. 明年618的三个最重要的改进是什么？

**【避坑指南】** 复盘的第一原则是**对目标说话**——先还原活动前定的目标与口径，再谈结果；没有目标对齐的复盘是成绩汇报。

## 二、数据说明

**表1 活动配置表 `promo_config`**

| 字段 | 类型 | 含义 |
|---|---|---|
| promo_id | STRING | 活动场次ID（预售/开门红/返场） |
| promo_stage | STRING | 阶段：presale/sale/return |
| start_dt / end_dt | DATE | 起止日期 |
| mech_type | STRING | 机制：full_cut满减/deposit_expand定金膨胀/coupon直减券 |
| threshold | DECIMAL | 门槛（满X元/券面额） |
| budget | DECIMAL | 该场次补贴预算 |

**表2 订单表 `orders`**（活动期及前后各60天）：order_id、user_id、pay_time、amount、status、is_new_user、channel、category。

**表3 券核销表 `coupon_use`**：user_id、coupon_type（无门槛/满199-30/满399-60）、issue_dt、use_dt、order_id、subsidy_amt。

**表4 流量表 `traffic`**：dt、channel、pv、uv、push_sent、push_open。

**口径预声明**：①活动GMV=活动期支付完成订单金额（剔除退款按T+15口径复算）；②"日常基线"=活动期前30天日均GMV经星期效应修正（周一~周日各自取前8周均值）；③新客=is_new_user=1且活动期首次支付。

## 三、复盘框架

```
目标对齐 → 结果确认（总量/节奏/同比环比）→ 拆解归因（流量×转化×客单；分阶段分人群分渠道）
```

## 四、数据清洗与基线构建（Python）

```python
import pandas as pd, numpy as np

orders = pd.read_csv('orders.csv', parse_dates=['pay_time'], dtype={'user_id':'str','order_id':'str'})
promo  = pd.read_csv('promo_config.csv', parse_dates=['start_dt','end_dt'])
coup   = pd.read_csv('coupon_use.csv',  parse_dates=['issue_dt','use_dt'], dtype={'user_id':'str'})
traffic= pd.read_csv('traffic.csv',     parse_dates=['dt'])

# 1) 订单清洗：唯一化 + 有效口径
orders = orders.drop_duplicates('order_id', keep='last')                       # 状态流转取最新
valid = orders[orders['status'].isin(['已支付','已完成'])].copy()               # 有效支付
valid['amount'] = pd.to_numeric(valid['amount'], errors='coerce')
valid = valid[valid['amount'].between(0, valid['amount'].quantile(0.999))]     # 极端异常单截尾（保留真实大单）

# 2) 划分活动期与基线期
PROMO_S, PROMO_E = pd.Timestamp('2024-05-31'), pd.Timestamp('2024-06-20')
valid['period'] = np.where(valid['pay_time'].dt.date.between(PROMO_S.date(), PROMO_E.date()),
                           '活动期', '非活动期')

# 3) 星期效应修正的日常基线：取活动前56天（8周），按星期几求日均
base = valid[valid['pay_time'] < PROMO_S].tail(56*30000)  # 前8周订单
base = base[base['pay_time'] >= PROMO_S - pd.Timedelta(days=56)]
base['dow'] = base['pay_time'].dt.dayofweek
dow_avg = base.groupby('dow')['amount'].agg(cnt='count', gmv='sum')
baseline_daily = (dow_avg['gmv'] / 8).sum()               # 修正星期分布后的"应有日均GMV"
print(f'日常基线日均GMV: {baseline_daily/1e4:.1f}万元')
```

**要点**：不做"活动期日均 vs 前30天日均"的粗糙对比——活动期周六日占比不同会引入偏差，**按星期几分别取均值再合成基线**才是干净的对照（这是本项目方法论上最值钱的一步）。

## 五、核心分析过程

### 5.1 目标达成与节奏

```python
promo_gmv = valid.loc[valid['period']=='活动期','amount'].sum()
target = 2.4e8
print(f'活动GMV {promo_gmv/1e8:.2f}亿, 达成率 {promo_gmv/target:.1%}')

# 分阶段节奏：预售/开门红/返场的日GMV曲线 vs 基线
daily_gmv = valid.groupby(valid['pay_time'].dt.date)['amount'].sum()
stage_map = promo.set_index('promo_stage')[['start_dt','end_dt']].apply(tuple, axis=1)
# 输出：预售期贡献28%、开门红41%、日常腰31%、返场期低于开门红35% → 开门红是绝对主力
```

**结论1（模拟）**：GMV 2.31亿，达成率96%——**未达标**；缺口主要在返场期（低于预期35%），预售期和开门红均超额。

### 5.2 真增量测算（去透支）

```python
# 增量 = 活动期GMV - 同期基线；再算活动后30天"回补缺口"检验透支
promo_win = valid[valid['period']=='活动期']['amount'].sum()
increment = promo_win - baseline_daily * 21            # 活动期21天
after30 = valid[(valid['pay_time']>PROMO_E) & (valid['pay_time']<=PROMO_E+pd.Timedelta(days=30))]['amount'].sum()
base30   = baseline_daily * 30
post_gap = after30 - base30                            # 活动30天相对基线的差值
print(f'活动期增量: {increment/1e4:.0f}万; 活动后30天相对基线: {post_gap/1e4:.0f}万')
# 输出示意：活动期增量 +4850万；活动后30天 -1200万（低于基线）→ 透支率≈25%
```

**结论2**：活动期增量约4850万，但活动后30天GMV低于基线约1200万——**约1/4的需求被从未来"搬"到了活动期**（透支）。真实净增量≈3650万。对比去年618透支率38%，今年有所改善（预售分流+定金膨胀锁定更早）。

### 5.3 补贴效率（券ROI分层）

```python
coup_valid = coup.dropna(subset=['use_dt'])                       # 已核销券
spent = coup.groupby('coupon_type')['subsidy_amt'].sum()

# 核销ROI = 用券订单GMV增量 / 补贴成本（增量用"用券订单客单-券门槛/2的对照估计"简化，
# 更严谨做法：用券人群 vs 匹配未用券人群的GMV差分）
merged = valid.merge(coup_valid, on='order_id', how='inner')
per_coupon = merged.groupby('coupon_type').agg(
    orders=('order_id','nunique'), gmv=('amount','sum'), subsidy=('subsidy_amt','sum'))
per_coupon['aov'] = per_coupon['gmv']/per_coupon['orders']
per_coupon['roi'] = (per_coupon['gmv'] - per_coupon['subsidy'])/per_coupon['subsidy']
print(per_coupon.round(2))
# 输出示意：
#   满199-30：核销率61%，ROI 3.8   ← 撬动凑单最有效
#   满399-60：核销率34%，ROI 2.9
#   无门槛10元券：核销率88%，ROI 0.6 ← 大量发给"本来就会买"的人，纯消耗
```

**结论3**：满减券ROI显著优于无门槛券；无门槛券核销率高但ROI<1，其中约55%的核销用户在活动前30天本就有购买行为（挤出效应）——下届建议将无门槛券改造成"**沉睡/新客定向券**"。

### 5.4 拉新质量

```python
new_in_promo = valid[(valid['period']=='活动期') & (valid['is_new_user']==1)]
new_daily    = valid[(valid['period']=='非活动期') & (valid['pay_time']<PROMO_S) & (valid['is_new_user']==1)]

def retain(df, users, days):
    last = df.groupby('user_id')['pay_time'].max()
    first= df.groupby('user_id')['pay_time'].min()
    return (last - first).dt.days.gt(days).groupby(users).mean()   # 首单后N天内复购率示意

# 30日复购对比：活动新客 vs 日常新客
print('活动新客30日复购率:', round(0.112, 3), '日常新客:', round(0.168, 3))  # 模拟结果
# 渠道拆解：达人直播渠道活动新客复购率仅0.06 → 冲动型拉新
```

**结论4**：拉新10.2万达成，但**活动新客30日复购率11.2%，比日常新客16.8%低1/3**；拆渠道后定位到"达人直播"渠道拉新质量最差（复购率6%）——**拉新数字达标，质量未达标**。明年目标应改为"**有效新客数**（首单后30日复购≥10%的新客）"。

### 5.5 护栏检查

- 毛利率：活动期毛利率21.3%（日常25.1%），为目标的89%（红线85%之上，但补贴结构中直减券占比过高是主因）；
- 履约：大促48小时发货率92%（要求90%达标），客诉率上升0.4pp（可接受）；
- 退货率：T+15口径下活动订单退货率19.8% vs 日常13.5%——"凑单退货"集中在满减门槛附近订单（门槛附近客单价分布的尖峰证明了凑单行为）。

## 七、业务建议（明年618的三个最重要的改进）

1. **券结构改造（预期补贴效率+30%）**：无门槛券转为"定向券"（只发新客/沉睡用户，预计节省补贴约18%，挤出效应数据支撑）；满199-30档位扩量（ROI最高），满399-60门槛下调至349测试弹性。
2. **拉新考核改口径**：从"新客数"改为"有效新客数（30日复购≥10%）"；对达人直播渠道设置质量门槛（低于8%复购率停投），预算向自有会员裂变迁移（该渠道活动新客复购率19%，是被低估的渠道）。
3. **透支管理**：预售定金膨胀前置锁定（本届已验证有效：透支率38%→25%）；返场期改为"会员专场+存货清仓"精准补量，避免与开门红重复消耗大额补贴。

**沉淀资产**：①星期效应修正基线模型（可复用于所有活动评估）；②券ROI分层测算模板；③"有效新客"口径定义（进入公司指标字典）。

**面试追问预演（6问+要点）**：

1. **透支率怎么算的？** 活动后30天GMV相对基线的缺口 ÷ 活动期增量；基线做了星期修正；同时对比去年同期透支率做时间序列可比。
2. **券ROI为什么不用核销率衡量？** 核销率高只说明券被用掉，不说明"增量"——用券的人可能本来就会买；所以要用对照人群差分（本项目用简化对照，严谨做法PSM/DID）。
3. **无门槛券"挤出效应"怎么验证的？** 用券用户中活动前30天有购买行为的占比55%，显著高于自然比例；且这些用户的客单价分布与无券时一致——说明券只是"降价卖给本来要买的人"。
4. **为什么活动新客复购率低就说明拉新质量差？** 已排除渠道结构变化（分渠道内部对比）；低复购主要来自冲动型下单（客单低、退货率高），符合"羊毛/冲动"画像。
5. **如果只有一周时间做复盘，你砍掉什么？** 优先级：达成拆解+券ROI+拉新质量三件事是决策必需；透支分析可简化为"后14天对比"；星期修正可先用同比代替——体现"给决策的最小充分分析"意识。
6. **你的建议如果老板不同意怎么办？** 用AB小流量验证（如无门槛券定向化在5%用户上先测），用数据迭代而不是辩论——分析师的坚持来自"可验证"而非"我认为"。
